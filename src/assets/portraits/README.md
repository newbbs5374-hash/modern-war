# 인물 사진 넣는 곳

이 폴더에 아래 이름으로 그림을 넣으면 게임에 바로 나와요. 그림이 없으면 지금 임시 그림(이모지·국기)이 그대로 나와요.

- 파일 형식: png · jpg · webp (webp가 가장 가벼움)
- 권장 크기: **정사각형 512×512** (1:1). 얼굴이 가운데보다 약간 위에 오게
- 화면에서는 동그랗게 잘려 보여요. 네 모서리는 잘리니 중요한 건 가운데에
- 한 장에 300KB 이하 권장(휴대폰에서 빠르게)
