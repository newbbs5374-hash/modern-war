# 인물 사진 넣는 곳

이 폴더에 아래 이름으로 그림을 넣으면 게임에 바로 나와요. 그림이 없으면 지금 임시 그림(이모지·국기)이 그대로 나와요.

- 파일 형식: png · jpg · webp (webp가 가장 가벼움)
- 권장 크기: **정사각형 512×512** (1:1). 얼굴이 가운데보다 약간 위에 오게
- 화면에서는 동그랗게 잘려 보여요. 네 모서리는 잘리니 중요한 건 가운데에
- 한 장에 300KB 이하 권장(휴대폰에서 빠르게)

## 인물 얼굴 60장 (11/23 인물·부처)
- 파일 이름 `face-{생김새}-{성별}-{나이대}-{번호}.png` (예: `face-ea-m-60-02.png`)
- 생김새 ea·sa·we·ee·me·tr / 성별 m·f / 나이대 50(59세까지)·60(60세부터)
- 같은 묶음 그림을 사람 약 100명이 나눠 써요. 없으면 출신 아이콘이 보여요.
- 명령문: 프로젝트 파일 `guides/face-art-prompts.md`, 참고 그림 `guides/face-art-ref.zip`
