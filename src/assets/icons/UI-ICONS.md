## 순서

1. 채팅창 1개를 열고 **첫 그림 때만** 참고 그림 3장을 첨부해요.
2. 아래 회색 상자 문장을 **한 장씩** 붙여 넣어요(같은 창에서 16장 차례로, 그래야 그림체가 맞아요).
3. 문장 끝에 적힌 **저장 이름 그대로** 저장해요(예: `icon-ui-home.png`).
4. 다 만들면(몇 장만이어도) zip 하나로 올려 주세요. 제가 잘라서 넣어요.

요령: 흰 배경이 나오면 "배경을 투명하게 다시". 만화처럼 나오면 "더 실사처럼, 만화풍 말고". 그림이 작게 나오면 "물건을 화면에 꽉 차게 크게".
