## 화풍: 반실사

애니메이션·만화풍이 아니라 **반실사**(실제 같은 비율·재질, 고급 모바일 전략 게임 그림 느낌)로 만들어요. 만화처럼 나오면 "더 실사처럼, 만화풍 말고"라고 고쳐 달라고 하세요.

## 만들 때 요령

1. 결과가 흰 배경으로 나오면: **"배경을 투명하게 다시 만들어 줘"** 라고 한 번 더 말하세요(창 1·창 3만. 창 2 지형은 투명이 아니어야 해요).
2. 그림을 내려받을 때 **명령문에 적힌 파일 이름 그대로** 저장해 주세요(예: `unit-tank.png`).
3. 마음에 안 들면 "더 단순하게", "오른쪽을 보게", "글자 지워 줘"처럼 고쳐 달라고 하면 돼요.
4. 다 만든 그림(몇 장만이어도)을 이 채팅에 올려 주시면 제가 게임에 넣어요.
