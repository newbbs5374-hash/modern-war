# 현대전 사령관 (시험판)

현대전 배경 2D 시뮬레이션 게임의 시험판입니다. 기획 단계이고, 디자인은 임시 도형·글자입니다.

## 1단계: 뼈대

- 실시간 세계 시계: 실제 1시간 = 게임 하루. 게임을 꺼 두어도 흐릅니다.
- 시간당 누적: 내 봉급(받기 전 12시간치까지 쌓임), 13개 나라의 국방예산·병력.
- 지도: 가상 대륙 5개, 나라 13개(연합 색·전선·휴전선·성지).
- 나라 데이터: 거점 도시, 시작 수치, 신앙, 특별 병과, 특수 능력, 시작 구도(전쟁·휴전·연합).
- 저장/불러오기: 브라우저 자동 저장 + 백업용 저장 코드.
- 시험용 버튼: 시간 건너뛰기, 시계 빠르기(×60, ×3600), 계급 바꾸기.

전투·진급·내정은 다음 단계입니다.

## 화면 묶음 (용흔 화면 구성 참고)

- 휴대폰 세로 비율 틀(PC에서는 가운데 세로 화면). 위 띠·아래 메뉴는 고정, 가운데만 스크롤.
- 위 띠: 본부에서는 장교 요약 + 재화 + 설정, 다른 화면에서는 ← · 화면 이름 · 재화 · 설정 · 본부. 재화를 누르면 재화 말풍선.
- 아래 메뉴 6칸: 작전(강조) · 장교 · 부대 · 훈련 · 나라 · 상점.
- 본부: 시계, 작은 세계 지도, 임무, 봉급 받기, 나라 금고 / 오른쪽 줄: 전령 · 의뢰 · 도감 · 시험.
- 아직 없는 기능은 "N단계" 표시와 계급 잠금(🔒)으로 자리만 둠.
- 주소 끝 `#화면이름`으로 새로고침해도 같은 화면.

## 2단계: 세계 움직이기

- 가상 AI 지도자 13명(성향 4가지: 공격형·방어형·경제형·기회주의). 새 게임에서 무작위로 바꿀 수 있음.
- 실제 15분(게임 6시간)마다 AI가 판단: 나라 쌍마다 긴장도가 오르고, 100이 되면 휴전이 깨지거나 선전포고. 연합국은 60% 확률로 끌려 들어옴. 전쟁이 길어지면 피로도가 쌓여 휴전.
- 신앙 사건(고대 성도): 빛의 언약 ↔ 성검 교단 사이 긴장이 크게 오름.
- 침공: 전쟁 상대의 도시를 공격(자동 계산). 이기면 도시 방어도가 깎이고 0이면 점령. 내 나라를 50% 더 노림. 바다 건너 침공은 덜 자주·약하게.
- 점령지 반란으로 도시가 원래 주인에게 돌아가고, 망한 나라도 되살아남. 남의 도시는 수입 절반.
- 지도: 우리와의 관계 색 / 묶음 색, 도시 점(지금 주인 색, 흰 테두리 = 점령됨). 전령: 우리나라 소식 / 세계 소식.
- 숫자는 `src/game/balance.ts` 아래쪽. 60일을 돌려 보고 강대국이 한쪽을 다 먹지 않게 맞춤.

## 3단계: 사람(진급·스탯·부관·장군·라이벌·해임)

- 진급: 공훈 + 훈련 별(+ 장군급은 지도자 신뢰도)을 채우면 진급 심사 작전(2시간). 떨어지면 6시간 뒤 재도전. 진급하면 공훈·별은 0부터.
- 임무(임시): 게시판 3개(방어·기습·정찰·호송·구출), 실제 1~2시간. 스탯·부관 특기로 성공 확률이 정해지고 세계에 영향(방어도·병력·명성·정보). 4단계에서 직접 싸우는 전투로 바뀜.
- 간이 훈련(임시): 훈련 일정 최대 6개, 실제 4시간마다 1개. 별 1~3개와 스탯이 오름. 같은 훈련은 하루 3번째부터 절반. 5단계에서 미니게임으로 바뀜.
- 스탯 9개, 계급마다 상한이 오름(20 + 계급×10).
- 부관: 중위 1 · 소령 2 · 대령 3명. 임무에 같이 가서 경험이 쌓이고, Lv.3이면 장군으로 승격 가능.
- 장군: 준장부터 1~5명(승격 또는 봉급 3000으로 영입). 내 나라 도시 방어가 오름.
- 라이벌 장교 3명이 같이 진급. 대장에서 총사령관이 되려면 평판이 라이벌보다 높아야 함.
- 해임: 준장부터 내 나라 도시를 잃으면 지도자 신뢰도가 떨어짐. 25 아래면 경고, 72시간 안에 40을 못 넘기면 한 계급 강등.
- 빠르기: 하루 3번 접속 기준 소위 → 총사령관 약 59일(숫자는 `src/data/officers.ts`, `src/game/officer.ts`).

## 4단계: 전투 틀 5개

모든 전투에 🤖 자동전투 · ×0.5/×1/×2 · ⏩ 즉시완료(자동전투와 같은 결과). 같은 씨앗이면 같은 결과(1초 20번 계산).
피해·명중·상성·사기·엄폐는 `src/battle/calc.ts` 공통 계산기를 씀. 장교 스탯이 부대 공격·체력·시야·이동·사기에 들어감.

- ① 격자 턴제(`grid.ts`): 7×9 칸, 내 차례 → 적 차례. 지형(숲·건물 엄폐, 언덕 시야+), 안개, 숨기, 기습 ×1.5, 포위 ×1.25, 의무병 치료. 방어(깃발 8턴) · 기습(전멸) · 구출(인질) · 정찰(목표 칸). 부관마다 분대원 1명.
- ② 옆보기 실시간(`side.ts`): 투입 점수로 병과 투입, 명령 포격(자리 고르기)·연막·돌격(고를 때 멈춤). 호송 · 돌파 · 버티기.
- ③ 포물선 대결(`arty.ts`): 각도·힘·바람, 땅이 패임, 포격 스탯이 높으면 안내선이 길고 피해가 큼. 8발씩.
- ④ 위에서 본 슈팅(`shooter.ts`): 끌어서 움직이기, 기관포 자동, 물결 9개 뒤 폭격기.
- ⑤ 퍼즐·카드(`puzzle.ts`): 모병(카드 고르기) · 정보(암호 4자리) · 보급(길 잇기) · 해킹(추적 게이지).
- 연결: 임무가 도착하면 "직접 싸우기"(방어·기습·구출·정찰 = ①, 호송 = ②) 또는 "자동 계산(스탯)". 별이 많으면 공훈 ×1.2/×1.4. 진급 심사도 계급마다 다른 틀(`src/battle/spec.ts`).
- 훈련 화면의 "전투 연습장"에서 임무 전투를 보상 없이 해 볼 수 있음.

## 5단계: 훈련 12개 · 작전 · 대전투

- 훈련 12개가 직접 하는 미니게임(`src/battle/spec.ts`의 TRAINING_BATTLE). 잠입·전술·해상 = ①, 통솔 = ②, 체력 = 장애물 코스(`course.ts`), 사격 = 사격장(`range.ts`), 포격 = ③, 항공 = ④, 모병·정보·보급·해킹 = ⑤.
- 계급이 오르면 같은 훈련도 커짐(혼자 잠입 → 분대 3명, 박격포 → 자주포 → 함포 → 미사일 유도, 분대 → 중대 → 대대 지휘).
- 자동·즉시완료를 쓰면 별 최대 2개, 져도 스탯 +0.5. 같은 훈련 별 3개를 10번 받으면 특기(전투 스탯 +).
- 해상: 구축함·잠수함, 잠수함은 붙어 있거나 소나(구축함 행동)로만 보임.
- 작전(대위부터): 임무 게시판 3번째 칸. 2~3판을 이어 싸움(고지 뺏기·방어선·돌파·보급선·사령부 기습·잠수함 사냥). 앞 판을 이기면 다음 판이 쉬워짐. 이기면 우리 도시 방어도 +, 적 도시 방어도 −(0이 되면 점령).
- 대전투(준장부터, 12시간마다): 전쟁 중인 나라 도시 하나를 골라 5판(해킹 → 포격 → 제공권 → 시가지 → 사령관 생포). 시가지는 꼭 이기고 3판 이상 이기면 점령. 어떤 판이든 "부관에게 맡기기"(별 최대 2).

## 6단계: 내정 · 전략 자원 · 생산 · 무역

- 전략 자원 7종(강철·석유·알루미늄·티타늄·희토류·리튬·반도체). 도시마다 나는 자원이 다르고(`src/data/economy.ts`), 점령 도시는 절반.
- 내정 시설 3개: 산업(예산·자원) · 인프라(생산 속도) · 복지(모병). 경험치는 저절로 + 내정 일(1시간)로 쌓고, 총사령관이 되면 모아 둔 경험치로 5단계까지 올림(기획서대로).
- 병과 생산(준장부터): 국방예산 + 자원 + 시간. 나라 특별 병과도 만듦. 만든 부대는 병력·전투력이 되고 전투력이 높으면 대전투가 쉬워짐.
- 무역(준장부터): 전쟁 중이 아닌 나라와 사고팔기. 상대 지도자 성향에 따라 값이 다름(경제형 싸게, 공격형 비싸게, 연합 10% 할인).
- 저장 4판: 예전 저장도 이어짐(`src/game/save.ts`). 계산은 `src/game/economy.ts`.

## 7단계(1): 승리 · 균형

- 승리 조건(총사령관이 된 뒤): ① 연합 승리 = 우리 + 연합국이 세계 도시 76% · ② 정복 승리 = 우리 혼자 48%. 둘 중 하나를 7일 동안 지키면 승리. 이기면 엔딩, "명예의 전당"(첫 화면에 남음)에 올리고 다른 나라로 새 판.
- 내가 점령한 도시는 반란이 1/4(복지가 높으면 더 적음), 만든 부대 전투력만큼 침공을 더 잘 막음. 점령지를 잃으면 신뢰도가 조금만 떨어짐.
- 시설 올리기는 기획서대로 총사령관부터(그전엔 경험치만 모음).
- 균형 시뮬: `npm run sim`(하루 3번 접속, 자동전투만). 총사령관까지 약 83~87일, 직접 싸워 별을 더 받으면(`SKILL=1`) 약 55~60일.

## 7단계(2): 완성작에 가깝게 · 화면 새 옷

- 화면: 탭·팝업·도움말(?)·접기 부품(`src/ui/kit.tsx`)으로 모든 화면을 그림 타일 위주로 바꿈. 글은 팝업·도움말 안에. 그림은 임시(이모지·국기).
- 부관: 하루 한 번 선물(인연 +8)·특별 훈련(경험 +60), 2~4시간 심부름(정보 수집·보급 조달·전공 쌓기, 그동안 전투에서 빠짐), 인연 30/60/90에 이야기(60: 전투 공격 +1, 90: 임무 성공 +5%). 레벨이 오르면 전투에서 더 셈, 특기별 효과(정찰 시야·이동, 저격 명중, 통신 사기, 공병 방어).
- 훈련: 숙련도 5단계(초보~달인, 단계마다 +10%), 최고 기록, 오늘의 훈련(2배).
- 전투: 날씨(맑음·밤·비·안개·눈 → 시야·명중·이동·바람), 상대 나라 이름, 적 지휘관(쓰러뜨리면 별 +1).
- 총사령관: 나라 → 외교에서 선전포고·휴전 제안·연합 제안(12시간마다), 대전투 대기 절반(6시간).
- 균형 시뮬: 총사령관 뒤 약 7~9일에 승리.

## 8단계: 본부 화면 · 가상 나라

- 나라·지도자·도시 이름을 모두 가상으로 바꿈(대장 요청 11/22). 나라 id(us, kr…)는 저장 호환을 위해 그대로.
  - 리버티아(us)·화련(cn)·볼가르(ru)·아이젠마르크(de)·히노모리(jp)·애셔랜드(uk)·수리야(in)·가람(kr)·카라한(tr)·하리온(il)·샤르반(ir)·스테포바(ua)·철령(kp)
- 국기도 가상(`src/ui/flag.tsx`, 색 띠 + 문양 SVG).
- 본부: 우리나라 땅 그림(`src/ui/HomeLand.tsx`, 나라마다 모양 다름) 위에 건물 아이콘 + 이름. 위에 주요 재화, 왼쪽 위 세계지도, 그 밑 주요 임무.
